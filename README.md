# Estudos de Spring Boot

Repositório dedicado ao registro prático e implementação de conceitos do ecossistema **Spring Boot**, desenvolvido a partir do minicurso prático ministrado pelo canal **Dev Souza** no YouTube.

O objetivo do projeto é consolidar a transição do Java puro para o desenvolvimento de APIs corporativas, compreendendo os mecanismos de inversão de controle, persistência relacional e controle de acesso e autenticação com o framework.

---

##  Objetivo
Compreender a arquitetura de uma aplicação moderna com Spring Boot, construindo uma base sólida para o desenvolvimento de APIs RESTful estruturadas, seguras e documentadas.

---

##  Tópicos Abordados

- **Arquitetura em Camadas:** Separação de responsabilidades utilizando o padrão Controller, Service, Repository e DTO.
- **Injeção de Dependências e IoC:** Ciclo de vida de beans e gerenciamento de dependências com anotações (`@Autowired`, `@Service`, `@Component`, `@RestController`).
- **Construção de APIs REST:** Mapeamento de rotas e verbos HTTP (`@GetMapping`, `@PostMapping`, `@PutMapping`, `@DeleteMapping`) e controle de status com `ResponseEntity`.
- **Persistência de Dados:** Integração com Spring Data JPA, mapeamento de entidades relacionais e consultas derivadas.
- **Segurança e Autenticação (Spring Security):** Configuração de filtros de segurança (`SecurityFilterChain`), controle de rotas públicas/protegidas e criptografia de senhas.
- **Documentação de Endpoints:** Mapeamento interativo de rotas via Swagger/OpenAPI.

---

##  Tecnologias Utilizadas

- **Linguagem:** Java
- **Framework Principal:** Spring Boot
- **Módulos do Ecossistema:**
  - Spring Web
  - Spring Security
  - Spring Data JPA
  - SpringDoc / OpenAPI (Swagger)
- **Gerenciador de Dependências:** Maven
